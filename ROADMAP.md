# Roadmap

This file defines milestone intent only. It does not own current status, next actions, or acceptance claims. See `STATUS.md`, `TASKS.md`, and the active task record for live state.

| Milestone | Intended outcome |
| --- | --- |
| M0 | Product boundaries, governance, architecture, data contracts, task/ADR/testing baseline |
| M1 | Local application shell and honest workspace navigation |
| M2 | File authority, conflict-safe API, index rebuild, and search |
| M3 | Story hierarchy, planning projections, writing, Codex, Progression, and character knowledge foundations |
| M4 | Provider adapters, model settings, Prompt/context assembly, call logs, and non-writing AI foundation |
| M5 | Durable Proposal/Review loop, Workshop conversations, safe Agent tools, Council, and explicit visual acceptance |
| M6 | Reference ingestion, evidence-linked retrieval, research notes, and semantic search |
| M7 | Versioning, backup, Markdown/DOCX import/export, and Word round trip |
| M8 | Startup/recovery hardening, performance, security, user documentation, and long-term release readiness |

Milestones are completed only through their NS task and acceptance records. A milestone label must not be used as a commit identity; each M5 product-mainline change, for example, uses one `NS-5xx` task at a time. Separately numbered support work may improve repository governance, but it does not advance or renumber the product mainline.
