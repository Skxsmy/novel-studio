# 安全与隐私

- 默认仅监听 `127.0.0.1`。
- 路径必须解析后验证仍在所选作品库内，拒绝 `..`、符号链接逃逸和绝对路径注入。
- API 密钥使用 Windows 凭据系统；开发阶段允许环境变量，但日志必须脱敏。
- 模型调用只能使用作者显式选择的 Provider 和模型配置；资料源只能进一步收紧上下文权限。
- 禁止本地模型静默回退到云模型。
- HTML 导入需清洗；DOCX/EPUB/PDF 解析器执行 25 MiB 输入上限、ZIP 路径/符号链接/条目数/展开大小/压缩比/CRC 检查和 20 秒解析超时。
- 导入器不读取文档声明的外部文件或网络资源；DOCX 外部文件/包关系被拒绝，普通超链接只作为文字关系保留且从不获取。
- 作者提交网页地址时只允许一次受控 `http`/`https` 获取：拒绝本机、局域网、IPv4 映射 IPv6、凭据化和非公开目标；每次跳转重新解析并验证全部地址，再把连接固定到一个已验证地址。最多四次重定向，禁止循环和 HTTPS 降级，并限制响应大小、HTML/XHTML 内容类型和十秒超时。不执行脚本、不递归跟踪链接，清洗后的单页快照作为受管理原件；普通文件解析器仍不得联网。
- NS-605 的向量 sidecar 是唯一的窄范围 SQLite 扩展例外：进程只从已安装并固定版本的 `sqlite-vec` 包解析扩展路径，只在每个 Research Database 的独立派生向量连接上加载。请求、设置、环境变量、作品库文件、SQL 值和数据库元数据都不能提供或改变扩展路径；权威文件连接和词法索引连接仍禁止扩展加载，任意扩展路径和 SQL `ATTACH` 仍被禁止。
- 无遥测。错误报告由用户主动导出并默认去除正文与凭据。
