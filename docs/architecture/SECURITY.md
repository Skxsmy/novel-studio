# 安全与隐私

- 默认仅监听 `127.0.0.1`。
- 路径必须解析后验证仍在所选作品库内，拒绝 `..`、符号链接逃逸和绝对路径注入。
- API 密钥使用 Windows 凭据系统；开发阶段允许环境变量，但日志必须脱敏。
- 模型调用只能使用作者显式选择的 Provider 和模型配置；资料源只能进一步收紧上下文权限。
- 禁止本地模型静默回退到云模型。
- HTML 导入需清洗；DOCX/EPUB/PDF 解析器执行 25 MiB 输入上限、ZIP 路径/符号链接/条目数/展开大小/压缩比/CRC 检查和 20 秒解析超时。
- 导入器不读取文档声明的外部文件或网络资源；DOCX 外部文件/包关系被拒绝，普通超链接只作为文字关系保留且从不获取。
- 作者提交网页地址时只允许一次受控 `http`/`https` 获取：拒绝本机、局域网、IPv4 映射 IPv6、凭据化和非公开目标；每次跳转重新解析并验证全部地址，再把连接固定到一个已验证地址。最多四次重定向，禁止循环和 HTTPS 降级，并限制响应大小、HTML/XHTML 内容类型和十秒超时。不执行脚本、不递归跟踪链接，清洗后的单页快照作为受管理原件；普通文件解析器仍不得联网。
- NS-605 的向量 sidecar 是唯一的窄范围 SQLite 扩展例外：进程只从已安装并固定版本的 `sqlite-vec` 包解析扩展路径，只在每个 Research Database 的独立派生向量连接上加载。请求、设置、环境变量、作品库文件、SQL 值和数据库元数据都不能提供或改变扩展路径；权威文件连接和词法索引连接仍禁止扩展加载，任意扩展路径和 SQL `ATTACH` 仍被禁止。
- NS-606 的模型检索网关只接受 Provider native tool call 协议中的三个严格只读工具。活动数据库白名单、`model-context` Source 权限、结果页长、相关性、调用次数、无进展和字符/token 估算预算均由服务器执行上下文固定；工具参数不能覆盖。持久审计只保存工具名、参数哈希/长度、数据库与引用标识、结果计数、预算和通用错误，不保存查询原文、完整 Source/Chunk 正文、密钥、Authorization/Cookie 头、Provider 原始响应或文件路径。未知工具、模拟工具文本、未激活数据库、`never` Source、过期引用和完整数据库转储请求均失败关闭。
- 冻结的 NS-609 Research Note 兼容路径仍必须保持原有安全边界：只接受服务端从当前 Research Database 权威解析出的 Source Evidence，拒绝客户端自报正文、hash、私有路径或跨库身份，且不得返回受管理原件路径、凭据引用或密钥。ADR-0026 不批准该功能，只要求在作者决定保留或移除之前不降低现存数据保护。
- Research 生命周期命令只接受目标 ID、当前 revision 和有界确认/替换输入；服务器重新解析当前 authority、所有者和引用，客户端不能宣布“无阻断项”。Source 替换不能提供受管理目标路径，重新解析不能访问网络，网页刷新只能复用受控获取策略。永久数据库删除先把经过解析和验证的目标根原子移动到作品库内部隔离删除区，再只从该路径清理；跨数据库 ID、符号链接、路径注入、不可读引用或不匹配的完整名称都失败关闭。阻断响应只返回对象类型、可读名称和有界状态，不返回 Source 正文、原件路径、查询、密钥或 Provider 数据。
- 无遥测。错误报告由用户主动导出并默认去除正文与凭据。
