# 安全与隐私

- 默认仅监听 `127.0.0.1`。
- 路径必须解析后验证仍在所选作品库内，拒绝 `..`、符号链接逃逸和绝对路径注入。
- API 密钥使用 Windows 凭据系统；开发阶段允许环境变量，但日志必须脱敏。
- 模型调用只能使用作者显式选择的 Provider 和模型配置；资料源只能进一步收紧上下文权限。
- 禁止本地模型静默回退到云模型。
- HTML 导入需清洗；DOCX/EPUB/PDF 解析器设置大小、压缩比、时间和内存限制。
- 导入器不读取文档声明的外部文件或网络资源。
- 作者提交网页地址时只允许一次受控 `http`/`https` 获取：拒绝本机、局域网、凭据化和非公开目标，限制重定向、响应大小、内容类型和超时，不执行脚本、不递归跟踪链接，并把清洗后的快照作为受管理原件。普通文件解析器仍不得联网。
- 无遥测。错误报告由用户主动导出并默认去除正文与凭据。
