# M0 任务说明

## NS-001 仓库蓝图

产物：治理文档、功能矩阵、架构、数据模型、API、安全、ADR、测试策略和工作区骨架。

验收：新参与者只读仓库文档即可说明产品目标、当前状态、数据权威来源和唯一下一任务。

## NS-002 基线检查

产物：依赖锁文件、Git 仓库、类型检查、测试、构建命令。

验收：`npm.cmd run check` 通过；状态和交接文档记录真实结果。

## NS-003 完整产品规格

产物：完整产品、UX、AI 编辑团队、资料分析、导入导出/版本备份和需求追踪规格；更新 AI 开发必读顺序。

验收：不了解原始聊天的后来者能够说明产品最终效果、全部功能边界、关键不可简化原则及每个里程碑的完成条件。
