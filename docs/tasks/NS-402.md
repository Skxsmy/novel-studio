# NS-402：AI 契约分区与最小持久化

状态：完成。

## 目标

把 M4 的核心契约从单体 `packages/contracts/src/index.ts` 拆出来，并建立不依赖真实模型的本地文件持久化。

NS-402 完成后，后续任务可以在稳定文件格式上实现 ProviderAdapter、上下文装配、提示词渲染和调用日志，而不用再向 `ProjectRepository` 或 contracts 单体文件继续堆代码。

## 非目标

- 不接真实 Provider。
- 不做 Provider 连接测试。
- 不实现上下文装配逻辑。
- 不实现提示词渲染。
- 不实现 SSE 或模型调用。
- 不实现候选变更应用。
- 不保存 API key 明文。

SQLite 仍是派生索引；删除后可以从 YAML 文件重建。

## 安全边界

- `ModelProfile.credentialRef` 只保存凭据引用，不保存 API key。
- 测试确认模型配置文件不包含 `sk-` 形式密钥。
- `ModelCallLog` 只保存哈希、状态、用量和错误分类；不保存认证头。
- `ContextBundle` 是审计快照，读取旧调用上下文时不重新生成当前上下文。
