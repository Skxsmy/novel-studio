# NS-404：模型设置、凭据边界与云端权限

状态：完成。

## 目标

建立 M4 的模型配置入口和安全边界，让后续非写入型 AI 调用可以在明确权限下选择模型，而不是把供应商、密钥和回退规则散落在代码里。

## 已交付

- 新增模型配置 API：
  - `GET /api/v1/series/:seriesId/ai/model-profiles`
  - `POST /api/v1/series/:seriesId/ai/model-profiles`
  - `PUT /api/v1/series/:seriesId/ai/model-profiles/:profileId`
  - `POST /api/v1/series/:seriesId/ai/model-profiles/:profileId/test`
  - `GET /api/v1/series/:seriesId/ai/model-profiles/:profileId/models`
  - `PUT /api/v1/series/:seriesId/ai/cloud-policy`
- 新增 `CredentialRefSchema`，拒绝把明显的明文密钥写入模型配置。
- 新增 `CredentialStore` 抽象与 Windows Credential Manager 实现。
  - 当前任务只建立凭据系统边界，不新增输入真实密钥的 UI。
  - 环境无法访问凭据系统时返回明确错误，不退回明文文件。
- 历史版本曾以 `series.yaml` 的 `cloudPolicy` 控制作品级云端权限。
- NS-408 后当前主路径已移除全局“只允许本机模型”开关；安全边界改为 Provider 显式选择、凭据引用、资料级 `local-only/never` 过滤和禁止静默回退。
- 云端模型缺少凭据引用时会被服务端拒绝。
- Provider 不可用时不会退回 MockProvider。
- 新增设置页“模型与资料权限”：
  - 可切换作品级云端权限。
  - 可添加本机验收模型。
  - 可建立 OpenAI / Ollama 配置占位。
  - 可保存模型名称、模型代号、调用权限和系统凭据引用。
  - 可执行连接测试并显示可读结果。

## 安全边界

- 不保存真实 API key。
- 不把凭据写入作品目录、调用日志、控制台输出或 Git。
- `credentialRef` 只是系统凭据的引用名称；真实密钥只能由凭据存储实现读取。
- 不实现静默回退。测试模型、云端模型和本机模型必须由配置显式选择。
- 不新增真实网络 Provider。真实 Provider 属于 `NS-408`。
