# NS-406：提示词模板、角色与版本

状态：完成。

## 目标

把 M4 的角色职责和提示词从代码占位改为可审计的文件、版本和预览流程。NS-406 不调用真实模型，不生成正文，也不把 AI 输出写入已确认设定或故事进展。

## 已交付

- 新增可审计的角色文件格式。后续 M5 Workshop Agent 隔离工作已移除早期固定全局内置角色补种；当前角色由用户或明确功能入口创建。
- 每个角色保存为 `prompts/roles/<role-id>.yaml`，包含：
  - 职责。
  - 工作人格。
  - 不负责事项。
  - 反对义务。
  - 禁止行为。
  - 输出约束。
  - 可读取范围。
- 角色可由用户修改和归档。
- 新增提示词模板格式，保存为 `prompts/templates/<prompt-template-id>/v<version>.yaml`。
- 新增 Preset 格式，保存为 `prompts/presets/<preset-id>.yaml`。
- 新增声明式模板渲染器：
  - 只支持 `{{变量名}}` 占位符。
  - 支持组件拼接。
  - 缺少必填输入时拒绝预览。
  - 出现 `{{ user_request.toUpperCase() }}` 一类表达式时拒绝渲染。
- 模板修改只生成新版本，不覆盖旧版本。
- `ContextBundle` 现在会纳入 `prompt-template` 项，记录实际使用的模板 ID、版本和渲染结果。
- 设置页新增“角色与提示词”分区：
  - 查看内置角色。
  - 复制角色。
  - 编辑自定义角色的名称、工作人格和反对义务。
  - 查看模板版本。
  - 保存模板新版本。
  - 预览最终提示词。

- `POST /api/v1/series/:seriesId/ai/presets`

## 不变量

- 角色和模板由用户显式创建；当前不再依赖全局内置角色补种。
- 模板版本文件不可被新版本覆盖。
- 模板渲染不能执行任意 JavaScript 或表达式。
- 缺少必填输入时不能继续“调用”流程。
- 上下文预览使用真实角色和模板文件，不再使用占位职责。
- NS-406 不调用 Provider，不写正文，不写 Canon，不更新摘要、人物状态、故事进展或角色所知。
