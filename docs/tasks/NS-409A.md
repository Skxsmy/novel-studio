# NS-409A：图像模型协作式 UI 重做与全局视觉系统

状态：完成；NS-409C 纠偏补充已记录  
日期：2026-06-21

## 背景

NS-404 至 NS-408 已实现模型设置、提示词预览、上下文预览和 AI 候选闭环，但界面逐渐出现三类问题：

- 页面混合旧书页风、后台表单风和硬黑框终端风；
- 主路径曾暴露或暗示过多开发者关心的信息；
- 浏览器验收截图覆盖不足，无法系统判断 UI 是否真的好看、统一、清晰。

本任务不改变 M4 的模型和上下文能力，只建立可持续的 UI 协作流程，并对现有主页面做一次全局视觉系统收敛，为后续 `NS-409` 的上下文预览和调用记录 UI 打底。

## 目标

- 建立 `docs/design/ui-redesign/` 设计资产目录。
- 为重要页面保存当前截图、图像模型目标图和实现后截图。
- 将“真实截图 → 功能清单 → 图像模型目标图 → 代码落地 → 再截图 → 图像模型复查”的流程写入权威 UX 规格。
- 重做全局视觉令牌和主要组件风格，使主界面更接近“安静写作空间 + 克制战术工作台”。
- 移除主路径中明显不适合作者视角的审计字段或文案。
- 扩展 Playwright 浏览器验收截图覆盖，避免 UI 任务只抽查设置页或写作页。

## 非目标

- 不实现完整调用日志 UI；仍属于 `NS-409`。
- 不重新设计底层模型配置、ProviderAdapter 或凭据协议。
- 不把图像模型生成图当作产品功能来源；功能仍以产品规格、源码和任务清单为准。
- 不追求一次性完成所有未来页面重排；本轮先统一视觉系统和关键主路径。

## 后续给 NS-409 的要求

- 上下文预览和调用日志 UI 必须沿用本轮视觉系统，不得重新发明一套后台表格样式。
- 调用 ID、PromptTemplate version、请求 / 响应哈希、Token 用量等只能进入记录详情或高级信息。
- 新增任何 AI 相关面板都必须扩展浏览器截图，而不是只做 DOM 断言。
- 若后续 UI 继续调整，应从 `NS-409A-implemented-review-target-v1.png` 和实现后截图开始，而不是只凭实现者主观判断。

## NS-409C 纠偏补充

用户指出 `NS-409B-plan-target-v2.png` 和 `NS-409B-write-target-v2.png` 与此前满意的目标图偏离，且实现者在两套样式覆盖层中反复做局部 CSS 调整，导致“以为改了”而实际效果变化不明显。本补充记录本轮纠偏，不把它伪装成 NS-409A 原始完成状态。

### 纠偏原则

- 不做逐像素形式主义；但必须保留目标图、真实截图、实现截图和差异说明。
- 图像模型不是一次性灵感来源，而是页面级设计协作者；规划页和写作页必须以页面级目标图为实现模板。
- 不再靠新增无必要控件解决审美问题；优先解决结构比例、视觉权重、字体气质、边框密度和主次关系。
- 主界面仍不展示调用 ID、Token、哈希、基准版本等开发者审计字段。

### 已完成的纠偏动作

- 移除未跟踪的第二套 `apps/web/src/ui-foundation.css` 覆盖层和 `main.tsx` 引入，避免 `styles.css` 与 `ui-foundation.css` 互相覆盖导致判断失真。
- 将 `NS-409B-plan-target-v2.png` 和 `NS-409B-write-target-v2.png` 在设计资产登记中标记为不采纳。
- 生成并保存新的页面级目标图：
  - `docs/design/ui-redesign/NS-409C-plan-target-v1.png`
  - `docs/design/ui-redesign/NS-409C-write-target-v1.png`
- 基于真实实现截图再次交给图像模型复查，并保存：
  - `docs/design/ui-redesign/NS-409C-plan-review-target-v1.png`
  - `docs/design/ui-redesign/NS-409C-write-review-target-v1.png`
- 规划页由单栏大画布改为三栏工作台：左侧层级树、中间故事板、右侧轻量规划检查栏。
- 写作页浏览器验收改为先输入真实中文正文再截图，避免用空白正文状态误判写作页 UI。
- 写作页标题和正文改为更接近文学稿纸的中文 serif 字体，降低后台系统黑体感。
- 规划页右侧动作按钮和场景卡选中态已降噪，不再使用厚黑框或过重主按钮。

### 仍需后续处理

- 写作页左侧结构栏的新增按钮仍偏表单化，需要继续按复查图降低存在感。
- 规划页尚未实现复查图里的底部“新建场景”工作台入口；当前仍通过写作页层级入口创建场景。
- 设定库、编辑室、待确认和设置页尚未经历同等深度的 NS-409C 页面级复查。
