# M3 任务说明

M3 把目前的真实场景纵向闭环扩展成可管理长篇结构与故事事实的工作台。任务必须按顺序执行。

## NS-301 Act/Chapter 契约

新增 `ActManifest`、`ChapterManifest`，Book 只引用 Act，Act 引用 Chapter，Chapter 引用 Scene。为当前 M2 作品提供无损迁移：从场景 frontmatter 的 `actId/chapterId` 推导缺失清单，迁移前建立快照。

验收：幕章改名、重排和场景跨章移动不改变任何实体 ID；损坏引用被检测而非静默丢弃。

## NS-302 真实规划视图

Grid、Outline、Matrix 和双时间线使用同一份查询结果。拖动只生成排序命令，服务端事务性验证后写回清单。

验收：四种视图切换不改变数据；移动后刷新保持一致；叙事顺序和故事时间可独立排序。

## NS-303 Markdown 编辑器

用 Milkdown 替代 textarea，原稿仍是 Markdown。作者备注、候选版本和隐藏资料保存为独立 Section 文件；审阅锚点采用块 ID + 引用文本 + 前后文重新定位。

验收：Markdown 往返不丢中文标点、段落和基础强调；外部修改后锚点可重定位或明确标记失效。

## NS-304 Codex

实现自定义类别、别名、标签、关系、AI 上下文策略和提及索引。Description 属于 Canon，Research 与 Canon 分离。

## NS-305 Progression 与角色知识

按叙事场景计算有效状态，故事时间仅用于时间线和矛盾检查。世界真相与角色知识分开查询，未来场景默认不可见。
