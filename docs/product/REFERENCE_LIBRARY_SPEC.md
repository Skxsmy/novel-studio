# 资料分析库规格

状态：权威功能规格  
依赖：`PRODUCT_SPEC.md`

## 1. 目标与边界

资料库用于摄入和分析用户已经获得的小说、论文、网页存档、数据说明及外部 AI 研究报告。它必须提供可追溯证据，而不是伪装拥有高质量联网搜索。

首版不内置 Tavily、Firecrawl 或浏览器抓取。未来获取器只负责把新资料送入同一摄入管线，不能绕过来源、权限和安全检查。

## 2. SourceDocument

每个来源保存：

- 稳定 ID、显示名称、作者、语言和来源类型。
- 原始文件副本或受管理路径。
- SHA-256、大小、导入时间和解析器版本。
- 作品归属与标签。
- 云端权限：继承作品、仅本地模型、禁止 AI。
- 解析状态、警告和失败原因。
- 版权/使用备注，由用户自行填写。

原始文件不可由分析过程改写。相同哈希再次导入时提示复用或建立新版本。

## 3. 支持格式

### TXT / Markdown

- 识别 UTF-8、UTF-16 和常见中文编码；不确定时要求用户选择。
- Markdown 保留标题层级、段落、列表、引用和链接目标。

### DOCX

- 使用语义样式识别标题、段落、列表、脚注、图片占位和链接。
- 默认禁用外部文件访问。
- 复杂排版、文本框顺序和样式丢失写入导入报告。

### 文本型 PDF

- 保存页码和页内顺序。
- 页面无可提取文本时标记“可能需要 OCR”，不输出空白成功结果。
- 不在首版执行 OCR。

### EPUB

- 验证压缩比、文件数量、路径逃逸和总体解压大小。
- 保留 spine 阅读顺序、章节标题和内部链接。

### HTML

- 清洗脚本、样式、事件属性和危险 URL。
- 不加载外部图片、字体、iframe 或脚本。
- 保留标题、正文、链接文字及原始来源 URL 元数据。

## 4. 解析结果与定位

解析生成层级结构：

`SourceDocument → Section/Chapter → Block → Chunk`

每个 Chunk 包含：

- 来源 ID 和解析版本。
- 章节、页码、段落或 DOM 路径等 `SourceLocation`。
- 原文和标准化搜索文本。
- 前后文引用。
- 语言检测结果。
- 内容哈希和顺序。

分析结论必须引用 Chunk 或更精确位置。仅有文档 ID、不含位置的引用不满足证据要求。

## 5. 检索

### 关键词

- FTS5 永远可用。
- 中文使用适合连续文本的 tokenizer 或字符 n-gram。
- 支持标题、作者、标签、语言和来源类型过滤。
- 结果高亮并显示来源位置。

### 语义

- 默认不开启，用户配置本地或云端 Embedding 后启用。
- 本地模型以可选下载形式提供，不把大型模型捆进基础安装包。
- 云端 Embedding 必须遵守作品和资料源权限。
- Embedding 记录模型、维度、版本和 Chunk 哈希；任一变化触发对应重建。

### 混合排序

关键词与语义结果合并时显示命中方式。语义相似不能被描述为原文直接支持；回答仍需引用实际文本。

## 6. 分析能力

可对选择的资料执行：

- 结构与章节功能分析。
- 人物弧、关系和出场分布。
- 主题、意象和母题追踪。
- 节奏、场景长度和叙述视角分析。
- 语言与文风特征提炼。
- 事实整理、观点分歧和未知项。
- 与当前作品的对照问题清单。

分析输出包含：结论、证据、适用范围、不确定项和模型信息。不得自动把参考作品的具体措辞加入生成 Prompt。

## 7. Research Note 与 Canon

- 原文资料属于 Source。
- 从资料提炼出的内容属于 Research Note。
- Research Note 默认不是故事事实。
- “转入 Codex”产生一个新的 Proposal，并要求作者说明它是现实参考、世界规则还是仅供灵感。
- 来源更新后，已有 Research Note 不自动改写；系统提示证据版本已变化。

## 8. 外部研究报告

由 Codex、其他 AI 或人工完成的报告可作为普通 Source 导入。报告中已有的链接和引用只是文本，除非解析器能验证并定位原始来源，否则不得提升为“已核实证据”。

## 9. 安全限制

- 每种格式有文件大小、解压大小、文件数量、解析时长和内存上限。
- 解析在工作线程或子进程中执行，可超时终止。
- 禁止路径穿越和符号链接逃逸。
- 不执行宏、脚本、嵌入对象和外部资源。
- 原始资料不能覆盖作品文件。

## 10. 验收场景

1. 导入中英双语 EPUB 后可按章节检索并回到原文位置。
2. 文本型 PDF 结果带页码；扫描 PDF 明确提示需 OCR。
3. 禁止 AI 的资料可关键词搜索，但不会进入本地或云模型上下文。
4. `local-only` 资料使用云端 Embedding 时在发送前被阻止。
5. 删除索引后可从 Source 重新解析/索引，不丢失 Research Note。
6. 恶意 EPUB 路径、HTML 脚本和 DOCX 外部文件引用被拒绝或隔离。
