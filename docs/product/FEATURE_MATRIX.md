# 功能矩阵

本矩阵将 Novelcrafter 研究转化为 Novel Studio 的原创产品需求。详细研究仍保留在 `E:\Codex\projects\novelcraft`。

| 功能域 | Novel Studio 决策 | 里程碑 |
|---|---|---|
| 幕章场景与多视图规划 | 采用并增加双时间线 | M3 |
| 结构化 block 正文、节拍、续写和局部改写 | 采用；Markdown 仅作为导入导出/兼容边界；所有 AI 结果先成为 Proposal | M3/M5 |
| Codex、别名、关系和 Progression | 采用并增加角色知识状态 | M3 |
| Workshop 与对话提取 | 采用；提取结果进入候选收件箱 | M5 |
| Persona、Preset、Prompt Component | 采用声明式模板，禁止任意代码 | M4 |
| 多模型连接 | 采用 ProviderAdapter，不绑定供应商 | M4 |
| Snippets、版本、归档、导入导出 | 采用 | M3/M7 |
| 资料分析 | 增强为证据化本地资料库 | M6 |
| 账户、套餐、支付、公共分享 | 排除 | 永久排除 |
| 实时协作、云同步、出版排版 | 首版排除并保留架构边界 | M8 后评估 |
