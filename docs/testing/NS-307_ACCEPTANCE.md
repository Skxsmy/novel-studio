# NS-307 验收记录

验收日期：2026-06-20

状态：完成。

## 目标

修复写作页“新场景”只能落到第一部的问题，同时改善写作页左侧作品结构布局，让部、幕、章、场景的创建入口更接近作者的实际操作路径。

## 实现

- `CreateSceneInput` 增加可选的 `bookId`、`actId`、`chapterId`；只要提供其中一个，就必须三个同时提供。
- `ProjectRepository.createScene` 会优先使用输入中的目标位置；未指定位置时保留旧行为，落到第一本书的第一个可用章节。
- 写作页“本章新场景”默认在当前场景所在章节创建。
- 每个章节标题旁新增“新场景”入口，空章节显示“给这一章添加第一个场景”。
- 写作页左侧结构栏加宽，并按部 / 幕 / 章分组呈现，按钮位置更明确。
