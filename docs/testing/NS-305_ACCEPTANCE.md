## 已实现行为

- 故事进展支持条目与关系两类目标，使用 `addition` 与 `replacement` 表达“追加事实”和“替换此前状态”。
- 角色所知支持“知道 / 相信 / 误解”，并与世界事实分离查询。
- 有效状态按读者叙事顺序计算，不因故事时间靠前而提前暴露后文内容。
- 证据支持正文场景、设定条目和关系；正文引文必须能在场景正文中找到。
- 设定库详情页新增“进展记录”“角色所知”“此刻有效”区域，并复用中文界面词表。
- Windows 启动脚本增加启动互斥锁；健康服务会被复用，端口被异常旧进程占用时不再另起一个后台服务。

## 已知且接受的行为

- 本任务只提供人工录入和查询，不自动从正文抽取事实，也不自动写入已确认设定。
- Replacement 只影响“此刻有效”的投影结果，不删除旧历史。
- “未来变化已隐藏”只允许显示数量，不能显示未来记录的摘要、证据或内部 ID。
- 当前没有应用内停止服务和托盘入口；启动脚本只负责安全复用或启动服务，不主动杀进程。浏览器验收时按用户明确授权手动停止了旧服务。
