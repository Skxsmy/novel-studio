验收日期：2026-06-20

## 背景

用户指出当前界面存在两个实际可用性缺口：

- 只能添加场景，不能从界面添加幕或章。
- 作品库非空时不能从界面添加新系列。
- 系列内部不能从界面添加新的“部 / 单本”，导致 `Series → Book → Act → Chapter → Scene` 的第二层缺失。

幕、章和场景的底层文件契约和 API 已在 NS-201、NS-202、NS-301 中实现；“部 / 单本”的创建入口在本任务补齐为正式能力，避免“产品规格写了五层结构，界面只露出半截”的偏差。

## 实现范围

- 作品库非空时显示“新建系列”表单；创建后立即打开新系列，并保留原有系列列表。
- `/api/v1` 增加 `POST /series/:seriesId/books`，创建新部时同步建立第一幕和第一章。
- 写作抽屉按“部 → 幕 → 章 → 场景”展示。
- 写作抽屉顶部提供“新部”入口。
- 每一部标题旁提供“新幕”入口；空部显示“给这一部添加第一幕”。
- 每个幕标题旁提供“新章”入口；空幕显示“给这一幕添加第一章”。
- 自动标题使用“第一部 / 第二部”“第一幕 / 第二幕”“第一章 / 第二章”等中文写作用语。
- 保持“新场景”现有默认落点规则，不在本任务混入指定章创建场景或拖拽重排。
